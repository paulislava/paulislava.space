# Продающая страница 404

Дата: 2026-10-10.

## Поведение

- Для отсутствующего адреса Next.js отдаёт статус 404 и показывает отдельную тёмную страницу в стиле портфолио.
- На первом экране есть понятное объяснение, переход к работам, возврат на главную и видимая форма с одним полем «Контакт».
- После отправки контакта открывается общий сценарий: предложение дополнить заявку и окно успеха. Используется тот же `/api/contact` с доставкой по почте и в support-bot.
- Общий контактный блок сайта на 404 скрыт, чтобы не дублировать форму.

## Проверка

- Локально прошли TypeScript, ESLint и сборка Next.js; страницу проверили на настольном и мобильном экранах.
- На production неизвестный адрес возвращает HTTP 404; проверены текст, ссылки, форма и открытие общего модального окна. Повторная отправка реальной заявки специально не выполнялась: доставка общего сценария уже проверена отдельно.
