# Проверка пароля загрузчика Proff

В резервной копии `uploadupdate.php` присваивание в условии позволяло загрузить файл без правильного пароля. При восстановлении `/proff/` обработчик исправлен: пароль сравнивается с сохранённым значением, некорректные типы и версия отклоняются. Изменяемые файлы вынесены в отдельный каталог с наследуемыми правами записи: иначе повторная загрузка после замены файла завершалась ошибкой доступа.

Исходный обработчик дал семь ошибок в HTTP-тесте пароля и версии; исправленный прошёл те же проверки. На реальном PHP FastCGI выполнены две последовательные загрузки каждого типа с неизменными контрольными суммами, проверен отказ без пароля и с неверным паролем. Скрипты проверки и восстановления: `scripts/proff-reserve/`.
